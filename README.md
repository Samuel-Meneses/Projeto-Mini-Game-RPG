# ⚔️ Mini Game RPG — Guerreiro Programador

Um mini game RPG desenvolvido em **JavaScript puro**, criado para praticar lógica de programação, estruturas de controle, funções, arrays e métodos de manipulação de dados.

O jogador assume o papel de um **Guerreiro Programador** e precisa enfrentar 5 inimigos respondendo perguntas de programação.

---

## 🎮 Sobre o projeto

O jogo possui **5 fases**, cada uma representando um nível crescente de dificuldade.

Para avançar, o jogador precisa responder perguntas corretamente durante as batalhas.

Ao vencer uma fase:

* 💰 recebe ouro;
* ⚔️ melhora seus equipamentos;
* 🎒 recebe uma recompensa;
* 🏰 avança para a próxima fase.

Ao perder:

* 📉 os equipamentos podem perder nível;
* 🧠 o jogador pode treinar;
* 🔨 pode melhorar os equipamentos no ferreiro;
* ⚔️ pode tentar a batalha novamente.

---

## 🧠 Sistema de perguntas

As perguntas são organizadas em níveis:

| Nível | Conteúdo                                    |
| ----- | ------------------------------------------- |
| 1     | HTML, CSS e JavaScript básico               |
| 2     | HTML, CSS e JavaScript básico/intermediário |
| 3     | Métodos de arrays em JavaScript             |
